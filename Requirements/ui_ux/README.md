# AI DLC Workbench · 가을톤 UI 시안

기준: [lwj-requirements.md](../lwj-requirements.md)

`index.html`을 브라우저에서 열면 바로 사용할 수 있는 HTML/CSS/JavaScript 시안입니다. 설치 및 빌드가 필요 없습니다. Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.

## 화면 및 스타일

- 크림색 작업 배경, 테라코타 강조색, 머스터드 승인 상태, 올리브 완료 상태
- AI DLC Board: 6단계 칸반, 현황 요약, 병목 안내, 검색 및 프로젝트·담당자·단계·레이블·차단 필터
- 내 검토함: 승인 요청·의견 요청·의사결정·PR 리뷰 분류
- SR 상세: 단계/체크리스트, 요구사항·Spec·Plan·결정·활동 로그, CLI 컨텍스트, Git Diff, 접이식 요약 패널
- SR 목록, 연동 상태 및 권한 안내 화면
- 작은 화면에서는 카드 영역을 가로 스크롤하고 상세 화면은 세로로 배치

## 주요 시연 흐름

1. Board의 `PAY-102`를 열고 `다음 단계`를 눌러 차단 사유를 확인합니다.
2. `결정 사항`에서 두 정책의 선택지와 근거를 입력해 확정합니다.
3. `Plan`에서 승인 후 다음 단계로 이동합니다. Implementation으로 변경됩니다.
4. CLI 영역에서 프롬프트를 생성해 확정된 결정과 승인 상태를 확인합니다.
5. Board와 검토함에서 미결정·승인 대기가 사라진 것을 확인합니다.
6. 문서 본문을 선택한 뒤 `의견 · 수정 요청`을 눌러 대상 영역을 포함한 의견을 등록합니다. 수정 요청은 상세에서 해결할 수 있습니다.
7. `AUTH-331`에서 체크리스트 완료 후 Review로 이동할 수 있습니다. Review → Done은 열린 수정 요청이나 PR 승인이 남아 있으면 차단됩니다.

## 시안 범위

모든 상태는 현재 페이지 메모리에만 유지되며 새로고침하면 초기화됩니다. 기존 시안 파일은 수정하지 않았습니다. 실제 Jira/GitHub 연결, CLI 실행, 서버 저장, 사용자 인증과 권한 검증은 구현하지 않았습니다. 외부 연동 버튼은 예시 정보를 표시하며 실제 서비스로 이동하지 않습니다.

문서는 SR별 예시 템플릿으로 렌더링하며 범용 Markdown 파서는 아닙니다. 댓글은 선택 텍스트를 대상 설명으로 저장하며 위치 추적, 답글, 멘션 알림은 포함하지 않습니다. 날짜가 지정된 검토 요청은 없으며 예시 우선순위로 정렬합니다. 리더 강제 이동은 사유를 기록하는 UI 데모입니다. 테스트 전략, 문서 확인 여부는 시드 데이터입니다.
