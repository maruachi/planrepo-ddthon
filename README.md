# PlanRepo

요구사항 초안을 AI와 다듬고, 문서와 시각화를 함께 검토해 승인하는 Inception Plan 프로토타입입니다.

## 테이블오더 1분 시연

아래 미리보기나 **영상 재생**을 누르면 재생 화면이 열립니다. 완성 문서, 업무 흐름, 화면 시각화와 최종 승인 결과를 60초로 담았습니다.
