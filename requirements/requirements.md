# PlanRepo 제품 입력 요약

이 파일은 제품의 출발 의도를 간단히 정리합니다. 현재 요구사항과 결정은 프로젝트 내부 기준 문서에 통합했습니다. 모든 경로는 프로젝트 루트 기준입니다.

## 현재 Inception 프로토타입 범위

현재 프로토타입은 하나의 SR에 올린 초안 원문을 **Inception Plan**으로 다듬고 검토하는 경험을 우선합니다. 사용자는 **문서**, **요약·시각화**, **공유·리뷰** 세 탭에서 현재 Plan을 이해하고 동료와 검토합니다.

하나의 비어 있지 않은 문서만으로도 검토할 수 있습니다. 요구사항, 사용자 시나리오, 진행 계획, 주요 구조, 주요 결정, 작업 단위는 완전한 예시의 구성이지 작성 의무가 아닙니다. `aidlc-docs/examples/delivery-cancel/README.md`에서 원문부터 문서 v3 검토·승인까지 실행한 로컬 시연을 읽을 수 있습니다. 이 결과는 가상 역할 시연이며 실제 직원 승인이나 실제 주문 처리가 아닙니다.

작성자는 의도와 중요한 결정을 확인하고, 문서 내용을 직접 수정하거나 AI 변경안을 반영할지 선택하며, 현재 버전을 최종 승인합니다. 시스템은 문서 구조와 관련 내용을 연결하고, AI의 참고 추천과 사람의 확정을 구분하며, 버전과 검토 이력을 관리합니다.

AI 질문에 모두 답하는 일, 근거를 별도로 다시 입력하는 일, 답변을 문서에 반영했다는 확인을 따로 남기는 일은 필수가 아닙니다. AI 질문과 근거는 문서 리뷰를 돕는 참고 정보입니다. 사람이 남긴 차단 수정 요청은 해결한 뒤 승인합니다. 이번 UI에는 Construction과 코드 생성·실행·배포 기능이 없습니다.

최신 합의 UX에서 사람은 작성·리뷰 안에서 초안을 입력하고, 질문의 답변 후보를 선택하거나 자유롭게 답하고, AI 보완안을 채택할지 결정하고, 문서를 리뷰한 뒤 현재 버전을 승인합니다. AI 정리·시각화는 결재 전 문서 검토의 선택 보조 기능입니다. AI와의 대화나 그래프 생성은 필수 단계가 아닙니다.

결재가 끝난 버전은 읽기 전용으로 유지하고 원래 승인 이력을 보존합니다. 화면을 꾸미기 위해 승인 뒤에 문서를 다시 바꾸는 단계를 두지 않습니다. 새 요구 변경이 있을 때만 명시적으로 개정안을 준비합니다. 문서 내용을 저장하거나 AI 제안·질문을 반영해 현재 검토 기준이 바뀌면 영향받는 범위를 재검토합니다. 열람과 AI 보완안 생성만으로는 현재 승인이 바뀌지 않습니다. 이 UX 원칙을 구현하고 격리 UI에서 검증했습니다. 브랜치 디자인 통합 검증 기록은 aidlc-docs/construction/build-and-test/reference-design-integration-report.md입니다.

완전한 예시의 여섯 문단은 기존 `requirements` ArtifactVersion 안의 H2 section이며 한 묶음으로 version이 바뀝니다. 문서마다 독립 version을 만들거나 정교한 semantic summary를 저장하지 않습니다. 화면의 요약과 구조는 현재 Markdown heading과 명시된 연결에서 만들며, 원문 ArtifactVersion이 최종 기준입니다.

일반 로컬 실행은 화면과 API를 같은 origin의 단일 포트로 제공합니다. 빌드와 실행 준비를 실제로 마친 뒤 `http://127.0.0.1:4173`에서 엽니다. Claude는 서버의 교체 가능한 provider adapter로 연결하며 브라우저에서 CLI를 직접 실행하지 않습니다. 기존 권한·검토·실행 제한과 승인된 전체 제품 자산은 유지합니다. 아래 내용은 승인된 전체 범위를 대체하지 않으며, 실제 빌드와 사용자 흐름 검증 전에는 프로토타입 완료를 뜻하지 않습니다.

## 목적

PlanRepo는 팀이 SR별 질문·요구사항·계획·결정을 함께 검토하고 승인한 구현 기준본을 만드는 협업 서비스입니다. 문서 생성과 사람의 검토·결정·승인을 구분합니다. 승인 후 변경이 생기면 영향받는 내용을 다시 검토합니다.

## 승인된 전체 제품 범위

- 하나의 팀·프로젝트와 가상 사용자·SR을 사용하는 기능 데모입니다.
- G1 요구사항 승인과 G2 구현 준비 승인을 실제 저장·권한·버전 검사로 처리합니다.
- 팀 보드·내 검토함·문서 검토·수정 요청·결정·활동 이력을 제공합니다.
- AI는 설치된 Claude CLI를 사용하고 provider와 model을 교체할 수 있게 준비합니다.
- Jira·GitHub는 Mock과 링크로 시작합니다. 구현 인계는 승인 버전을 고정한 Markdown으로 제공합니다.
- MRBS·테이블오더는 내부 검토 사례이며 사례 서비스를 개발하는 범위가 아닙니다.

## 프로젝트 안에서 이어가기

시작 안내는 `aidlc-docs/README.md`입니다. 자체 완결 제품 요구사항은 `aidlc-docs/inception/requirements/requirements.md` 버전 0.4입니다. 검토 사례는 `aidlc-docs/inception/requirements/reference-context.md`에 있습니다. 진행 상태는 `aidlc-docs/aidlc-state.md`에서 확인합니다.

이 요약은 추가 상세 조건을 상속시키는 문서가 아닙니다. 필수 동작과 수용 기준은 현재 제품 요구사항 본문에 정의합니다.
