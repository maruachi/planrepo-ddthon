# 스킬 없는 대조군 검토

다섯 독립 에이전트에 같은 출력 계약과 각 대화의 다음 한 턴을 요청했습니다. 새 스킬이나 평가 기준을 제공하지 않았습니다. 전체 원문은 `aidlc-docs/skill-development/intent-discovery/tests/baseline/`에 있습니다. 아래 평가는 원문을 읽고 판단했습니다.

| 사례 | 판단 | 관찰 |
|---|---|---|
| S1 | PASS입니다. | 목적을 묻고 실제 답변을 기다렸습니다. 임의 기술·정책을 확정하지 않았습니다. |
| S2 | FAIL입니다. | 현재 확인을 존중하고 기술 미결정을 남겼지만, 원문 또는 접근 가능한 출처 연결과 AI-DLC 단계 승인 구분이 없습니다. |
| S3 | FAIL입니다. | 중단과 미결정을 존중했지만, 원문·확인 범위가 없는 인계이며 다음 행동을 테스트·구현으로 안내했습니다. |
| S4 | PASS입니다. | 모순과 의미 변화를 지적하고 이전 v1 확인을 재사용하지 않았습니다. |
| S5 | PASS입니다. | 기존 목적을 다시 묻지 않고 세 설계 이탈을 식별했습니다. |

S2의 실제 인계는 “사용자는 의도서 v1이 자신의 생각과 일치한다고 확인했으며, AI-DLC 입력 문서로 인계해 달라고 요청했습니다.”라고 요약합니다. 수신자가 확인할 원문·출처 식별과 공식 요구사항 승인과의 구분이 없습니다.

S3의 실제 인계는 “확정한 요구사항을 기준으로 실패하는 권한 테스트를 작성한 뒤 구현합니다.”라고 다음 행동을 안내합니다. 스킬의 산출물은 AI-DLC 분석에 넘길 의도 입력이므로 단계의 구분을 유지해야 합니다.

이 실패는 기본 질문 능력이 부족하다는 증거가 아닙니다. 보완 대상은 일관된 의도서 계약과 인계 경계입니다. S3·S5 결과 JSON에는 본문 개행이 이중 이스케이프된 부분이 있습니다. 출력 직렬화 문제는 행동 실패로 집계하지 않고 읽을 때만 개행으로 해석했습니다. 원본 파일은 보존했습니다.

실제 관찰에 따라 스킬은 원문·지위·확인 버전·미결정·다음 단계를 의도서의 명시 필드로 정의합니다. 압박 상황에서도 중단을 존중하면서 인계 상태를 구분하도록 작성합니다.
