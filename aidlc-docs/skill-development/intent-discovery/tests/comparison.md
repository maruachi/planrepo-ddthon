# 동일 대화의 적용 전후 비교

다섯 시나리오를 대조군과 스킬 적용군에서 각각 새 에이전트로 실행했습니다. 각 에이전트는 해당 대화와 다음 한 턴 출력 계약만 받았습니다. 적용군에는 스킬 본문을 추가했습니다. root가 저장된 답변과 문서 전체를 읽고 평가했습니다.

| 사례 | 대조군 | 적용군 | 적용군에서 확인한 행동 |
|---|---|---|---|
| S1 최초 탐색 | PASS입니다. | PASS입니다. | 목적을 구체 장면으로 질문하고 `exploring` 기록과 원문을 남겼습니다. 사용자 답변을 생성하지 않았습니다. |
| S2 정상 인계 | FAIL입니다. | PASS입니다. | U1·A1·U2 원문과 의도 I1~I7을 연결했습니다. 현재 v1 확인을 재질문하지 않았고 요구사항·설계·구현 승인은 별도임을 명시했습니다. |
| S3 중단과 인계 | FAIL입니다. | PASS입니다. | `provisional_handoff`로 기록하고 대행·조회 정책을 후속 질문으로 보존했습니다. 기술 제안 위임을 구현 승인으로 확대하지 않았습니다. |
| S4 의미 변경과 종료 | PASS입니다. | PASS입니다. | v2 `paused`에 모순을 남겼습니다. v1 확인을 이전 버전에 보존하고 새 내용에 재사용하지 않았습니다. |
| S5 Inception 재진입 | PASS입니다. | PASS입니다. | 기존 목적·범위를 유지하고 SSE·임의 수치·통신 실패 표시를 구분했습니다. 새 정책만 질문하고 현재 Application Design에 차이를 인계하도록 기록했습니다. |

## 검토 근거

대조군 원문은 `aidlc-docs/skill-development/intent-discovery/tests/baseline/`, 적용군 원문은 `aidlc-docs/skill-development/intent-discovery/tests/green/`에 있습니다. 시나리오 원문은 `aidlc-docs/skill-development/intent-discovery/tests/fixtures/`에 있습니다.

S2 적용군은 “이 확인은 의도서 v1에 대한 확인입니다. 아직 작성되지 않은 요구사항, 설계, 구현 계획의 승인을 뜻하지 않습니다.”라고 인계 경계를 명시합니다.

S3 적용군은 “사용자가 이 v1 문서 전체나 T1~T3을 확인한 발언은 없습니다.”라고 확인 범위를 구분하고, 사용자의 중단 요청을 그대로 따릅니다.

S4 대조군은 모순과 과거 확인 재사용을 잘 차단했습니다. 적용군은 추가로 마지막 종료 요청을 존중해 질문 없이 재개 지점을 보존했습니다. 이 추가 차이를 대조군의 새 실패로 소급 집계하지 않았습니다.

일부 결과는 문서 개행을 이중 이스케이프로 저장했습니다. 이는 테스트 결과 포장의 오류이므로 원문을 보존하고 표시할 때만 해석했습니다. 본문 의미 검증과 JSON 구조 검증을 구분했습니다.

## 해석 범위

대조군 3/5, 적용군 5/5가 정의한 행동 기준을 충족했습니다. 서로 다른 다섯 상황의 단일 표본 비교이며 동일 상황의 통계적 반복 실험이 아닙니다. 효과의 크기나 완벽한 의도 포착 확률을 뜻하지 않습니다. 독립 최종 검토와 실제 여러 턴의 대화 검증을 추가로 진행합니다.
