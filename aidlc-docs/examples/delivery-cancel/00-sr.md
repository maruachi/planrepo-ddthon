# 처음 올리는 초안

[이미지 예시 체험] 배송 전 주문 취소·환불

고객센터를 기다리지 않고 고객이 주문 상세에서 직접 주문 전체를 취소할 수 있게 합니다.
배송 전 전체 주문만 직접 취소합니다. 취소 확정 직전에 배송 상태를 다시 확인합니다.
이미 배송이 시작됐다면 주문을 유지하고 자동 환불 없이 반품 방법을 안내합니다.
일부 상품만 취소하는 경우는 이번 범위에서 제외하고 고객센터로 안내합니다.
취소 요청 버튼을 반복해서 눌러도 주문 취소와 환불 요청은 한 번만 처리해야 합니다.
주문 취소 완료와 환불 완료는 다릅니다. 환불 접수, 환불 상태 확인 중, 환불 완료를 구분해 보여 줍니다.
환불 서비스 응답이 늦으면 '환불 상태 확인 중'으로 안내하고, 30분 안에 확인되지 않으면 담당자에게 알려 확인합니다.
환불 금액은 실제 결제 금액 기준입니다. 이미지의 예시 주문은 상품 45,000원 - 할인 9,000원 + 배송비 3,000원 = 환불 접수 39,000원입니다.
환불은 기존 결제 수단으로 요청하며 통상 3~5영업일이 걸릴 수 있다는 안내를 표시합니다.
쿠폰 재발급, 부분 취소 금액 계산, 배송 후 실제 반품 처리, 실제 결제 실행은 이번 Plan의 범위에 포함하지 않습니다.
주문 상세 화면, 취소 확인 화면, 취소 결과와 환불 상태 화면이 필요합니다.
구성은 고객 화면, 주문 취소 API, 주문 상태 저장소, 배송 상태 조회, 환불 서비스이며 취소 확정과 배송 시작의 경합을 다뤄야 합니다.
이번은 PlanRepo의 문서 리뷰·결재를 체험하는 예시입니다. 실제 고객 주문이나 결제를 실행하지 않습니다. 위 내용으로 Inception 문서와 상황별 시각화를 만들고 동료 검토자 한 명에게 검토받습니다.

이 예시는 PlanRepo 로컬 체험을 위해 작성했습니다. 작성자는 이 초안만 올리면 됩니다. 이후의 문단 구분과 버전 연결은 시스템이 처리합니다.
