# eSPEC 초안 Inception 시연 계획

## 목적과 범위

현재 PlanRepo에 사용자가 제공한 eSPEC 초안을 입력하고 Inception Plan 보완, 검토, 프로세스 시각화까지 실제 화면으로 시연합니다. 사용자가 한 사이클 실행과 녹화를 요청했습니다. eSPEC·Oracle 관련 내용은 계획의 대상이며 실제 서비스 구현이나 운영 DB 실행은 포함하지 않습니다.

기존 PlanRepo 개발 워크플로우를 재개합니다. 이미 표시한 welcome과 완료한 설계 승인은 반복하지 않습니다. 기존 사용자 문서와 진행 중인 소스 변경을 보존합니다. 로컬 데모 역할의 검토 결과와 실제 업무 승인을 구분합니다.

## 실행 체크리스트

- [x] 프로젝트 상태·제품 요구·현재 UI와 AI 준비 상태를 확인합니다.
- [x] 공통 AI-DLC 규칙과 확장 opt-in을 읽습니다. 세 확장은 기존 Enabled=No에 따라 본문 적용을 생략합니다.
- [x] 사용자 원문을 보존하고 기존 테스트·typecheck·build를 실행합니다. 최초 전체 테스트 442개 통과·1개 실패이며 실패 항목 재실행은 7개 통과했습니다. 전체 재검증은 48개 파일 443개 테스트 통과입니다. 코드 변경 없이 실행했습니다.
- [x] 화면 녹화를 시작하고 eSPEC 초안을 새 SR로 등록합니다. 등록 직후 제목 입력 오류를 현재 설명 편집에서 바로잡았습니다.
- [x] 실제 AI 질문과 Plan 보완을 실행합니다. 미확인 정보는 미확인으로 유지합니다. 질문 5개를 저장했고 첫 Plan과 추가 보완안의 실제 생성 기록을 확인했습니다.
- [x] 생성된 문서를 검토하고 Inception Plan에 반영합니다. 검토 기준과 시연 범위가 포함된 보완안을 선택해 문서 v2로 반영했습니다. 동시 요청·시각화 표현의 추가 보완을 진행합니다.
- [ ] 요약·시각화에서 상황별 흐름과 화면을 확인합니다.
- [ ] 로컬 시연 검토·결재를 진행하고 현재 문서 버전을 확인합니다.
- [ ] 녹화를 종료하고 영상의 재생 가능 여부를 검증합니다.
- [ ] 원문·최종 Plan·영상·실행 증거·검증 보고서를 정리하고 상태·감사 기록을 추가합니다.

## 검증 기준

`USE_YN = 'Y' AND FILE_UPLOAD_DTTM IS NULL` 판정, 한 파일이라도 오류인 문서의 노출, PRC/INS 범위, 기존 업로드 Service 재사용, 중복·동시 요청, 원본 소실, 부분 실패, 기존 운영 권한, 기간 제한·Pagination·Oracle 실행계획 검증을 최종 Plan에서 점검합니다. 미확인 구현 세부사항은 후속 확인으로 남깁니다.

콘텐츠는 Markdown·JSON 파싱, 경로, 코드 블록 균형을 확인합니다. 시각화는 앱의 원문 인용 검증과 실제 화면으로 확인합니다. 영상은 화면을 연속 녹화하며 완성 화면을 이어 붙여 실행한 것처럼 표현하지 않습니다.
