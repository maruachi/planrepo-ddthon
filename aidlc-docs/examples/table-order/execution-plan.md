# 테이블오더 Inception Plan 시연 계획

사용자가 제공한 초안으로 기존 PlanRepo의 전체 사용자 흐름을 실행하고 화면을 녹화합니다. 테이블오더 서비스는 계획의 대상입니다. 시연의 최종 범위는 문서 작성·AI 질문·보완·시각화·가상 역할의 검토·승인입니다. 실제 매장 시스템 구현이나 운영 배포를 승인받았다고 해석하지 않습니다.

## 진행

- [x] 현재 프로젝트와 승인된 프로토타입 범위, 공통 규칙, 확장 설정을 확인합니다.
- [x] 사용자 원문을 보존하고 시연 계획을 기록합니다.
- [x] 기존 테스트·타입 검사·빌드를 실행합니다. 테스트 48개 파일 443개와 타입 검사·빌드가 통과했습니다.
- [x] 실제 화면 녹화를 시작하고 원문으로 새 SR을 등록했습니다. SR-MVP, sr-63bb1d22-6550-4689-8284-bd9059e09fee입니다. 원본은 저장 상태를 확인하며 두 구간으로 녹화했습니다.
- [x] 실제 AI 질문 5개를 생성·저장하고 모두 답변했습니다. 원문 5초 기준과 시연 가정·구현 전 확인 사항을 구분했습니다.
- [x] 실제 AI 보완안을 두 번 생성했습니다. 첫 결과의 원문 누락·인용 오류를 보완했고 두 번째 결과는 앱 파서에서 ready입니다. 7개 노드·6개 관계·6개 상황·6개 화면을 확인하고 v2로 반영했습니다.
- [x] 문서 v3의 시각화 7개 노드·6개 관계·6개 상황·6개 화면을 확인했습니다. 원문 근거 버튼으로 사용자 시나리오 문단 이동을 검증했습니다.
- [x] 문서 v3을 가상 동료 검토자가 승인하고 담당자가 최종 결재했습니다. 새로고침 후 결재 완료 상태를 확인했습니다.
- [x] 녹화를 정상 종료했습니다. 6분 36초 편집본과 14분 47.83초 전체본을 만들고 전체 디코딩·주요 프레임·최종 문서·승인 기록을 검증했습니다.
- [x] 결과 보고서와 프로젝트 상태·감사 기록을 갱신했습니다.

## 검증과 시연 가정

16시간 인증과 식사 세션을 구분하고 첫 주문·이용 완료에 따른 이력 분리를 확인합니다. 메뉴 관리의 MVP 포함 여부, 고객 상태 실시간 갱신, 중복 주문과 실패 시 장바구니, 서버 가격 재계산, SSE 복구는 시연 가정 또는 후속 결정으로 명시합니다. 사용자 원문의 확정 요구와 추가 제안을 구분합니다.

콘텐츠는 Markdown 코드 블록 균형과 JSON 파싱을 검증합니다. 앱의 시각화 인용 검증과 실제 표시를 함께 확인합니다. 녹화는 실제 컴퓨터 화면 캡처이며, 두 원본 구간과 핵심 장면 편집본을 함께 보존했습니다. 마이크는 녹음하지 않았습니다.

확장 Security Baseline, Resiliency Baseline, PBT는 기존 Enabled=No에 따라 모두 적용을 생략합니다. 새 제품 동작을 변경하지 않으면 새 TDD는 생략하고 기존 검증을 실행합니다.
