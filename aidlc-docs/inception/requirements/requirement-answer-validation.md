## 범위와 설계 후속 사항

하루 내 구현 제약과 실제 CLI 연동·문서 비교·복원 요구를 함께 유지한다. 임의로 기능을 축소하지 않으며 이후 Workflow Planning에서 구현 순서와 소요를 평가한다. Q9에 따라 공유와 리뷰의 첫 버전 검증은 로컬 역할 전환으로 수행한다.

언어·프레임워크, 저장 방식, CLI 실행 제한, 버전 및 결정 이력 데이터 모델 등은 이후 설계에서 구체화한다. 추가 질문 C1 A로 Claude Code CLI와 로컬 macOS 실행을 확정했다. 모의 생성으로 대체하지 않는다. 설치·인증의 실제 동작 검증은 구현 단계에 남긴다.
