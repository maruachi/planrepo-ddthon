# Plan 시각화 방향

사용자가 제공한 예시 5장을 프로젝트 내에 보관했습니다. 예시는 특정 결제 업무의 요구사항이나 수치를 가져오는 자료가 아닙니다. Plan에 따라 적합한 형태로 내용을 풀어 보여주는 방식을 참고합니다.

- plan-overview.jpeg: 바뀌는 일, 진행 순서, 판단 기준과 승인 범위를 한눈에 보여줍니다.
- conditional-flow.jpeg: 조건에 따른 분기와 재확인·예외 경로를 보여줍니다. 노드를 선택하면 근거와 설명을 엽니다.
- scenario-branches.jpeg: 상황을 선택하면 해당 경로와 결과가 강조됩니다.
- scenario-screen.jpeg: 같은 상황의 화면 예시와 문구의 근거를 연결합니다.
- approval-scope.jpeg: 현재 Plan의 승인으로 무엇이 확정되는지 구분합니다.

## 이번 프로토타입 적용

AI가 Inception 본문과 함께 설명용 시각화 자료를 제안합니다. 사람이 Plan에 반영하기 전까지 저장된 내용과 결재는 바뀌지 않습니다. 시각화 자료는 같은 문서 버전에 포함되므로 검토자가 같은 내용을 확인합니다.

문서의 인용 구절과 섹션이 맞는 자료만 화면에 표시합니다. 관계·시나리오·화면·기준은 본문에 근거를 두어야 합니다. 모델의 의미 해석이 정확한지는 사람이 검토합니다. 인용 일치 검사만으로 의미적 정확성이나 승인을 주장하지 않습니다.

변화와 동작, 사용자가 보는 화면, 지킬 약속과 예외를 같은 Plan에서 오가며 읽습니다. 상황 선택은 계획의 예시를 탐색하는 기능입니다. 실제 업무를 실행하거나 측정값을 만들지 않습니다. 자료가 없는 Plan은 기존 문서 요약과 주요 구조를 표시하며 AI에게 내용을 보완할 수 있습니다.

전체 플랫폼 범위는 Inception까지입니다. 화면 예시는 구현 결과물이나 배포된 서비스로 표시하지 않습니다. 원문 열기와 현재 버전의 결재 확인을 연결합니다.
