## 1. 목표와 비교 축
- **목표(§13)**: 어떤 정보 배치가 두 핵심 과업을 가장 빠르게 만드는지 비교.
  - **T1** 지금 답할 질문 찾기(EPIC-B) · **T2** 이전 검토 이후 바뀐 것 확인(EPIC-D).
- **비교 원칙(NFR-VIS-1, MK-1)**: 공유 셸·가을톤 팔레트·시드·과업을 **고정**하고 SR 상세 **중앙 검토 영역만** 4종으로 변형.
- **변형 스펙트럼(비평 종합)**: 네 변형은 "동시성/밀도" 축 위의 단조 표본 — **V4(오프캔버스 1카드) → V1(단일 스크롤 컬럼·전부 DOM) → V2(2-pane) → V3(3-pane)**. 두 계열(집중형 {V4,V1} · 동시형 {V2,V3})로 뭉치지 않도록 각 변형의 시그니처를 아래처럼 확정.

## 2. 공유 셸 (4종 공통·고정, D-AD-2)
- **Sidebar**: 팀 보드 / 내 검토함 / SR 상세 내비 + `RoleSwitcher`(5역할) + `VariantSwitcher`(V1~V4) + 데모 초기화 안내.
- **Topbar(SR 상세 상단 고정)**: SR · 현재 작업 · **지금 필요한 행동** · 담당자 · **차단 이유**. 어떤 변형에서도 즉시 보임(US-H2 AC).
- **본문 화면**: 팀 보드(`Board`), 내 검토함(`Inbox`), SR 상세(`SrDetail` = `Topbar` + `DetailCenter` 슬롯).
- 팔레트(고정): `--rust #a65036` `--olive #687044` `--mustard #967023` `--bg #f5f2eb` `--paper #fffdf8` `--ink #352f29` `--line #e5dfd3` `--radius 12px`. **Google Fonts 제거 → 시스템 폰트 폴백**(NFR-SELF-1). `.terminal`·`.git-panel` 제거(Q5=A).

## 3. 화면 흐름
1. **팀 보드**: 4단계 칼럼(`SR 접수 → Inception → Construction 설계 → 구현 대기`). 카드는 세 facet + 대표 차단 원인. 차단 원인 클릭 → 통과 조건·즉시 해결 행동 제시 후 SR 상세 이동.
2. **내 검토함**: 단일 우선순위 목록 + 유형 필터 탭. 행 클릭 → 해당 SR 상세의 관련 질문/문서/수정 요청으로 이동.
3. **SR 상세**: Topbar 고정 + `DetailCenter`(현재 변형). `VariantSwitcher`로 V1~V4 즉시 토글(셸 불변). 게이트 통과 시 `구현 대기` → `HandoffContextView`(읽기전용 승인본+확정 답변 + 참고용 Code Generation Plan 구분 표시, AC-11).

## 4. 4종 변형 확정 정의

각 변형은 **동일 공용 위젯·서비스**를 쓰고 배치만 다르다. 네 행동·세 게이트·버전 고정 승인·수정 요청 라이프사이클·파서 오류·색 비의존 상태를 **모두** 표현한다(비평 갭 보정 반영).

### V1 — 단일 컬럼 집중 (Single-Column Focus)
- **시그니처**: 모든 블록이 DOM에 상주, sticky 섹션 점프 칩이 전 섹션 카운트를 보여주는 **스크롤 맵**(위저드 아님). 자기주도 스크롤, 최저 인지 부하.
- **배치**: 실행 초점 배너 → sticky 점프 칩 → 활성 질문 카드(유일 펼침) → 대기 질문 아코디언(파서 오류 포함) → 변경 요약/버전 비교 → 보조 접힘 스택(문서 트리·AI 실행·**수정 요청 라이프사이클**·팀·인계 게이트).
- **T1**: 배너 지시문 → 바로 아래 유일한 펼친 질문 카드에서 즉시 답변(스캔 없음). **T2**: 질문 아래로 스크롤/점프 → 변경 요약 → diff 펼침(단일 컬럼의 명시적 트레이드오프 = 순차).
- **갭 보정**: ③ 보조에 **수정 요청 라이프사이클(US-E1)** 노출, **과거 버전 열람 시 최신 승인 차단(US-D2)** 상태 추가.
- **가설**: 초심자·저관여 평가자(P6), 좁은/모바일 화면, 단일 필수 질문 응답에서 **최저 오류**.

### V2 — 좌우 2-pane 비교 (Split Compare)
- **시그니처**: **드래그 divider + 연동 스크롤 인과 추적**(diff 줄 ↔ 원인 질문 카드) — 다른 변형에 없는 유일 기능. 맥락(문서 트리·팀·의존성)은 서랍으로 **완전 분리**해 "두 pane, 그 외 없음"을 명확히.
- **배치**: 공통 sticky 액션 바(문서·버전 셀렉터·연동 토글·인계 게이트) + LEFT(질문·결정, AI 인라인) ‖ divider ‖ RIGHT(FR-REV-1 5영역 세로).
- **T1**: LEFT 필터('필수 2') → 첫 카드 답변(화면 전환 없이, RIGHT 유지). **T2**: RIGHT에 이전 승인본 대비 diff 상주 → 요약→diff 훑기, `↳Q2` 링크로 원인 질문 점프(연동 스크롤).
- **갭 보정**: 수정 요청 **확인 대기·제출자≠확인자**(US-E1) 상태를 RIGHT (3)/(5)에 명시; 버전 셀렉터가 **과거 버전 비교·최신 승인 차단(US-D2)** 구동.
- **가설**: 리뷰어(P4)의 "답하면서 무엇이 바뀌는지" 인과 검토(T1+T2 균형).


### V3 — 3-pane 콕핏 (Cockpit)
- **시그니처**: 상주 **좌측 맥락 레일**(문서 트리·유닛 타임라인·현재 위치·역할·정책) — "유닛 전반에서 내가 어디 있나"에 한눈에 답하는 유일 변형. 클릭 0회 병렬 스캔, 최고 밀도.
- **배치**: LEFT 맥락 레일 ‖ CENTER 질문 카드 스택(우선순위 정렬 + 카운터 칩) ‖ RIGHT 검토·승인·실행 dock(버전 비교·5단계 리뷰·**4행동 2×2**·3게이트·AI 인라인·수정 요청).
- **T1**: CENTER 상단 카운터 칩 + 우선순위 정렬 → 최상단 카드가 곧 답할 질문(0클릭). **T2**: RIGHT dock 최상단 버전 비교 상주 → diff → ⑤ 승인(0~1클릭).
- **갭 보정**: **[답변 저장] 중복 제거** — dock을 단일 정본으로, CENTER 카드 내 저장은 shortcut으로 시각 표시. (US-D2/US-E1은 이미 충실.)
- **가설**: 파워 유저·리더(P5)/개발자(P2)의 다수 유닛 트리아지, 넓은 화면(≥1200px)에서 T1·T2 병렬 처리량 최고.

### V4 — 점진적 공개 서랍 (Progressive Disclosure / Focus Mode)
- **시그니처**: **위저드 큐 + 오프캔버스 slide-over 서랍**(맥락 전부 서랍) — V1의 전부-DOM과 정반대 거울상. T2는 **강제 5단계 diff 위저드**(제목만 승인 방지, US-D3 준수). 스텝 칩으로 임의 큐 항목 점프 허용(비선형 제약 완화).
- **배치**: 스텝 칩 스트립(답변 3·확정 2·계획 1·검토 1·게이트 1·형식오류 1) → 위저드 내비(이전/다음) → 포커스 카드(5종: 답변/확정/계획/**검토(5단계)**/게이트) → 카드 행동 푸터(그 순간 주 행동 1개) → 서랍 트리거 바(문서 트리·전체 질문·버전 이력·**수정 요청**·AI 로그·관련 답변).
- **T1**: 큐 첫 카드가 곧 답할 질문(0클릭) 또는 [답변 3] 칩 1클릭. **T2**: [검토] 칩 → 5단계 위저드 진행, 마지막 단계에서만 승인 활성.
- **갭 보정**: **수정 요청 전용 포커스 카드 종류** 추가(라이프사이클 시연); 위저드 흐름에 **과거 버전 승인 차단(US-D2)** 명시.
- **가설**: 개발자(P2)의 혼합 큐 처리, 준수 강제 T2, 좁은 화면 최강.

## 5. 두 과업 · 변형 요약
