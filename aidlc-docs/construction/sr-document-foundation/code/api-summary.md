# U1 API 계층

LocalAppBoundary의 query/command가 SR·문서 서비스에 연결된다. 13개 경로, 공통 Result/오류, UTF-8/JSON/소속/허용 필드 검증, 로컬 Host/Origin, no-store, 요청 receipt 조회를 구현했다.

실제 HTTP/임시 파일 SQLite 테스트 5개 통과. 생성/조회/편집/비교/복원/이력/공개 설정, 잘못된 JSON/미지원 압축·형식/용량 초과, 응답 연결 파괴 후 receipt 확인, 동일 요청 재사용, 다른 입력 충돌, 최신 변경 후 원래 결과 재조회, 진행 중 요청과 준비 경합 뒤 커밋 우선 확인을 검증했다.

로컬 포트는 샌드박스 EPERM으로 첫 실행이 차단되어 승인된 npm test 권한으로 재실행했다. 실패 주입은 테스트 서버에만 있다. UI 초안과 불확실 결과 표시는 다음 단계에서 검증한다.
