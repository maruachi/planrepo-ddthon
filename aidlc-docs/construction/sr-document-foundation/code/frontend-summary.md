# U1 화면 계층

고정 6열 보드, 직접 SR 생성/첨부, 초기 요구사항과 문서 목록/본문/활동 이력, 과거 버전 선택, 편집·비교·새 버전 복원과 상태 표시를 구현했다. 작은 Markdown은 raw HTML 실행 없이 표시하고 원격 이미지는 alt 텍스트로 대체한다. 큰 문서와 diff는 200줄씩 표시한다.

UI 상태 테스트 6개 통과. 응답 유실 시 1회 확인/자동 재제출 없음, 비정상 성공의 불확실 처리, 원래 receipt 재조회, 명시적 충돌, 편집 초안 유지, 늦은 비교 응답 무시, CRLF/끝 개행과 200줄 경계를 검증했다.

화면/키보드/상한 입력의 실제 브라우저 확인은 verification.md에 기록했다. 준비 데이터는 실제 AI 실행 증거가 아니다.
