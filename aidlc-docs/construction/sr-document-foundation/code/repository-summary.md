# U1 저장 계층

SQLite 3.53.4 / better-sqlite3 13.0.3의 실제 임시 파일 DB로 저장을 검증했다. 6개 테이블, 소속 복합 FK와 최신 지연 FK, 불변 기록 트리거, WAL/FULL/100 ms, 보존형 마이그레이션과 키셋 페이지 조회를 구현했다.

저장·마이그레이션·페이지 테스트 12개 통과. 재열기 원문/빈 첨부 보존, 중간 오류/지연 FK 전체 롤백, 소속/포인터 오류, 불변 변경 거절, 두 연결 잠금, receipt 재사용/충돌, 손상/미지원 스키마 원본 바이트 보존, 같은 시각 목록과 본문 없는 사건을 확인했다.

서비스의 최신 편집 경합과 HTTP 응답 유실은 이후 단계에서 추가 검증한다. 실제 Run 소속 FK와 후속 사건 타입은 U2/U3 책임이다.
