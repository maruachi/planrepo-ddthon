# U1 업무와 비교 계층

SRInputPort는 직접 입력 정규화 경계이며 Jira 호출을 하지 않는다. SR/문서 서비스는 타입별 저장 포트를 사용하고 편집·복원의 불변 버전과 사건을 원자 확정한다. prepareGenerated는 SR/키/본문/중복/최신 전제를 검사하며 커밋하지 않는다.

업무·생성 준비·비교·실제 컴파일 워커 테스트 7개 통과. 입력 UTF-8 상한/잘못된 surrogate, 원문 보존, 편집 v2→복원 v3, 같은 편집/복원 차이, 빈 사람 편집, 오래된 기준, 생성 준비 중 저장 불변/이후 충돌, CRLF/공백/끝 개행/빈 본문/제목, 간략 비교의 원문 복원, 워커 경합/취소/시간 초과/고장 후 회복을 검증했다.

실제 AI 실행 및 Run 소속·늦은 결과 정책의 최종 검증은 U2에서 수행한다.
