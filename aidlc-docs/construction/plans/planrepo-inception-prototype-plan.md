# Inception Plan 프로토타입 구현 계획

최신 사용자 범위는 AI-DLC Inception까지입니다. SR별로 이 과정의 문서 전체를 Plan이라 부릅니다. 목적은 AI와 의도를 맞추며 문서를 작성하고, 주요 구조·결정을 요약/시각화해 공유·검토·결재하는 것입니다. Construction과 실제 코드 생성은 이번 플랫폼 범위에 포함하지 않습니다.

## 구현 결정

기존 저장·문서 버전·질문·댓글·수정 요청·승인 API를 재사용합니다. 프로토타입에서는 Inception 문서 묶음을 하나의 requirements artifact 버전으로 저장하고 화면에서 문서 섹션별로 보여 줍니다. 현재 Plan 버전 전체가 G1의 검토 대상입니다. 기존 개별 workflow/design/implementation 자료는 보존하고 참고 자료로 열 수 있게 합니다. 과거 G1 또는 G2 통과만으로 새 Inception Plan 결재 완료를 표시하지 않습니다.

최신 사용자 기본 화면은 문서, 요약·시각화, 공유·리뷰입니다. 초안 원문을 바로 읽고 편집하며 AI는 선택 기능입니다. 실제 업무의 문서 연결을 화면이 준비합니다. 개요에는 원문 기반 목적, 문서 현황, 주요 구조/결정, 확인할 질문과 승인 상태를 표시합니다. 시각화는 저장된 문서·결정의 근거와 연결하고 AI가 생성하지 않은 관계를 사실처럼 만들지 않습니다.

공유는 같은 로컬 플랫폼 내 SR 직접 링크와 Markdown 다운로드입니다. 공개 인터넷 게시나 외부 메시지 발송은 포함하지 않습니다. 링크 진입 시 현재 사용자 권한과 버전을 다시 조회합니다.

검토자 지정은 현재 프로젝트 멤버인 등록자·현재 담당자·관리자에게 허용합니다. 팀 정책 편집은 관리자만 허용합니다. 검토자 변경에 따른 재검토·이력 보존은 유지합니다.

## 실행 단계

- [x] IP1. 최신 사용자 범위와 용어를 확정하고 이전 완료 기록과 새 범위를 구분합니다.
- [x] IP2. 등록자 검토자 지정의 서버 권한·등록 폼·부분 실패 재시도·배정 UI를 연결합니다.
- [x] IP3. SR 상세를 Inception 문서 묶음 중심의 작업 공간으로 바꾸고 기존 자료를 보존합니다.
- [x] IP4. 실제 Claude 질문·답변·설명 보완·Plan 초안 확인/적용을 한 화면에서 연결합니다.
- [x] IP5. 저장된 Plan의 요약·구조 시각화·결정 표시·직접 링크·다운로드를 제공합니다.
- [x] IP6. 문서 섹션의 댓글·수정 요청·반영 확인과 현재 Plan 버전 결재를 연결합니다.
- [x] IP7. typecheck·build·관련 권한/저장 회귀·격리 브라우저 흐름을 확인하고 사용자 preview에 반영합니다.

IP2는 review-policy-service.ts, SRReviewAssignment.tsx, SRRegistrationForm.tsx와 관련 권한 검증을 변경합니다. IP3/IP5는 SRDetail.tsx, App.tsx, TeamBoard.tsx, 새 InceptionPlanWorkspace/PlanOverview와 표시 모델을 변경합니다. IP4는 새 InceptionConversation.tsx를 추가합니다. IP6은 새 PlanDocumentReview.tsx와 기존 ReviewSummary를 연결합니다. 공통 계약과 DB schema는 우선 유지합니다.

- [x] IP8. 사용자 예시에 맞춰 Plan 내용의 조건별 흐름·상황별 화면·약속과 예외를 원문과 연결해 탐색하는 시각화를 제공합니다.
- [x] IP9. localhost 별칭으로 화면과 API를 열고 사용자 서버에서 접근 오류가 사라지는지 확인합니다.
- [x] IP10. 이미지의 배송 전 취소·환불 예시를 실제 로컬 앱에서 작성·검토·결재하고, 결재 요청 뒤에야 드러나는 필수조건과 잘못된 완료 안내를 개선합니다.
- [x] IP11. 초안 원문을 기본 화면으로 삼고 AI 제안·시각화를 선택 기능으로 바꾸며, 별도 근거·질문 반영 확인과 수동 문서 연결을 기본 흐름에서 제거합니다.
- [x] IP12. 같은 배송 전 취소·환불 예시의 SR, Inception 문서, 리뷰와 승인 기록을 사람이 읽기 쉬운 프로젝트 내부 예시로 제공합니다.

## 결재 전 보완 흐름 추가 수정

사용자의 직접 체험에서 질문의 답변 선택, 리뷰 의견에서의 AI 보완, 시각화 확인을 건너뛰고 결재부터 안내한 문제가 드러났습니다. 기존 프로토타입 구현 승인의 후속 UI 수정으로 진행합니다. AI와 시각화를 필수 단계로 추가하지 않습니다.

- [x] IP13. 현재 질문 후보·문서 보완·리뷰·승인 코드를 확인하고 결재가 최종 확정이라는 흐름을 정리합니다.
- [x] IP14. 작성 중 질문 답변 후보 선택, 기존 제안 다시 열기, 리뷰 내용 기반 보완 요청을 연결합니다.
- [x] IP15. 문서와 리뷰에 보완·시각화 진입점을 배치하고 결재 완료본의 기본 화면을 읽기 전용으로 바꿉니다. 변경은 명시적인 개정안 준비에서 시작합니다.
- [x] IP17. 요청한 브랜치의 초안 작성 목업과 디자인 원본을 식별하고 재사용 범위를 비교합니다. 현재 작업·사용자 데이터는 유지합니다.
- [x] IP18. 확인된 디자인을 초안 작성 화면과 공통 셀렉트박스·텍스트박스에 반영하고 실제 저장·검토 API 연결을 검증합니다.
- [x] IP19. 프로토타입에서 검토자 지정만으로 검토 요청이 발송되지 않게 분리하고 명시적 요청을 확인합니다.
- [x] IP16. 격리된 UI에서 작성·검토 전 보완과 승인 후 열람/개정 준비를 확인하고 관련 회귀·typecheck·build를 실행합니다. 기존 승인된 사용자 문서는 변경하지 않습니다.

IP14는 InceptionConversation.tsx와 AI 보조 표시 모델, IP15는 InceptionPlanWorkspace.tsx, PlanOverview.tsx, PlanApproval.tsx, PlanDocumentReview.tsx, ReviewSummary.tsx, BundleReviewForm.tsx를 변경합니다. 기존 API와 DB schema를 사용합니다. 새 설계 단위·외부 기록·운영 배포는 없습니다.

## 수용 장면

사용자가 SR 초안을 등록하며 검토자를 선택합니다. 같은 SR에서 AI 질문의 뜻을 확인하고 답합니다. AI가 제안한 Inception Plan을 읽고 반영합니다. 개요에서 주요 구조와 결정, 미확인 내용을 확인합니다. 공유 링크로 들어온 검토자가 문단에 수정 요청을 남깁니다. 작성자가 내용을 수정하고 검토자가 반영을 확인합니다. 현재 문서 버전의 결재를 마치면 Plan 승인 상태가 표시됩니다.

이전 요구사항만 승인된 자료와 Inception Plan 승인을 구분합니다. 문서가 없거나 작성 중이면 완료로 표시하지 않습니다. 모델 실패·오래된 결과·버전 충돌·권한 거절을 사용자에게 보여 줍니다.

## 검증과 확장

최신 사용자 지시에 따라 새 TDD 루프와 전체 제품 수용성/성능 확대는 생략합니다. 권한 범위 변경은 최소 실제 DB 회귀로 확인합니다. 모델 호출은 별도 테스트 데이터로 제한합니다. 사용자 DB는 백업 후 유지하며 임의 시드를 다시 넣지 않습니다. 사용자가 요청한 배송 전 취소·환불 예시 SR 1건만 추가해 실제 과정을 시연합니다. Security, Resiliency, Property-Based Testing 확장은 기존 설정대로 비활성 N/A입니다.
