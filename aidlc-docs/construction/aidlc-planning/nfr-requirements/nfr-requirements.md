# U2 NFR

U1 Node 24/React/Express/SQLite와 localhost/입력 검증/원자 저장을 재사용한다. CLI는 별도 임시 작업 디렉터리에서 기존 인증으로 실행하고 도구 사용을 비활성화한다. SR 문서만 프롬프트 데이터로 전달하며 코드 생성 규칙 Part 2는 전달하지 않는다.

초기 설정: CLI 실행 제한 5분, stdout 8 MiB, 문맥 8 MiB, 현재 문서 최대 100개, 결과 문서 최대 100개, 질문 최대 20개, 질문 8 KiB/답변 64 KiB. 문서별 기존 1 MiB와 제목 4 KiB는 유지한다. 상한 초과는 실패이며 잘라내지 않는다. 이 수치는 초기 보호 설정이며 성능 SLA가 아니다.

한 프로세스가 실행을 소유하며 종료 시 자식을 정리한다. 재시작 시 중단 Run을 실패 처리한다. 자동 실행 재시도는 없다. Run 문맥·문서·사건은 파일 DB에 보존하고 로그에 원문·인증값을 출력하지 않는다. 실패·응답 유실·버전 경합을 구분한다.

검증은 실제 CLI 성공/실패, 저장 보존/원자성/늦은 결과, 질문/결정/회차, 타입 검사·빌드·브라우저 주요 흐름이다. 클라우드/부하 인증은 N/A. 비활성 확장 3개 N/A.
