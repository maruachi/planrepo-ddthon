# U2 실행 안내

작업공간 루트에서 기존 Node 24와 잠금 파일을 사용한다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:4310 을 연다. SR을 만든 뒤 계획 생성, 질문 응답, 문서 검토·승인, 다음 단계 생성을 진행한다. 같은 단계의 수정하여 다시 생성은 해당 Inception/Construction 회차를 늘린다. 마지막 코드 구현 계획을 승인한 뒤 구현 대기로 이동한다.

```sh
npm run typecheck
npm test
npm run build
npm start
```

환경 변수 PLANREPO_CLAUDE_PATH는 기존 인증을 사용할 Claude CLI 실행 파일, PLANREPO_RULES_PATH는 규칙 디렉터리다. 기본값은 claude와 앱 루트의 .aidlc-rule-details다. 상대 경로는 앱 루트 기준이다. .env.example은 값 예시이며 자동으로 로드되지 않는다. 기존 PLANREPO_PORT/PLANREPO_DB_PATH도 유지한다.

CLI는 계획 문서를 반환하며 실제 앱 코드·Git을 실행하지 않는다. 사용자 인증 설정을 사용하되 훅·도구·추가 MCP·프로젝트 설정은 비활성화한다. CLI 설치/인증/외부 서비스 접근은 실행 환경에 필요하다. 실패 시 SR의 생성 실패 안내를 확인하고 환경을 수정한 뒤 명시적으로 다시 생성한다.

실행 중 문서를 편집하면 이전 입력으로 돌아온 결과는 충돌 실패가 된다. 최신 문맥으로 재생성한다. 저장 응답이 유실되면 처리 결과 다시 확인을 사용한다. 결과가 계속 불명확하면 새 시도 준비 확인창에서 이전 요청의 불확실성을 확인한 뒤 최신 상태를 읽고 다시 시도할 수 있다. 자동 재제출은 없다.

스키마 v1 파일은 시작 시 원문·버전·사건·receipt를 유지하면서 v2로 마이그레이션한다. 미지원/손상 스키마는 시작을 중단한다. DB 백업은 앱 종료 후 DB 및 남은 WAL/SHM 파일을 함께 보관한다. 재시작 시 남은 실행은 중단 실패로 기록하며 자동으로 CLI를 재실행하지 않는다.
