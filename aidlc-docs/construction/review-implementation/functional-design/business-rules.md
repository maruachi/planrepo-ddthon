# U3 규칙

1. 작성자는 Inception/Construction의 SR에 대해 실제 소속 문서 버전으로 리뷰를 요청한다. 최신/과거 모두 허용하되 대상은 고정한다. 요청 내용은 필수이며 64 KiB 상한이다.
2. 요청은 SR 열과 계획 revision/자체 승인을 바꾸지 않는다. 미완료 리뷰가 있어도 U2 자체 조건을 충족하면 진행한다.
3. 리뷰어는 requested 리뷰의 원래 버전을 읽고 approve/request_changes와 필수 결과 내용(64 KiB)을 한 번 기록한다. 결과를 바꾸려면 작성자가 새 리뷰를 요청한다. 중복 결과는 같은 operation receipt로 확인하고 다른 중복은 충돌이다.
4. 요청 후 SR이 다음 단계로 이동해도 결과를 기록할 수 있다. 원래 버전/요청 내용을 변경하지 않는다. 비교·이력은 U1을 재사용한다.
5. 역할은 UI 시연용이며 서버도 요청/결과/수동 완료의 기대 역할을 확인한다. 독립 사용자 인증이나 보안 권한을 제공한다고 주장하지 않는다. 기존 문서 읽기·비교는 모든 역할에서 제공한다.
6. 작성자가 구현 대기 SR을 수동 완료한다. 기존 planning revision을 전제로 SR과 WorkflowState 및 사건을 원자 저장한다. 리뷰 미완료는 이 동작을 막지 않는다. CLI·Git·빌드를 호출하지 않는다.
7. 모든 변경은 operation ID로 원래 커밋 결과를 확인한다. 응답 유실은 재조회, 자동 재제출 없음. 실패 시 초안 보존. 목록은 기존 50/100 페이지 상한과 추가 조회를 사용한다.
