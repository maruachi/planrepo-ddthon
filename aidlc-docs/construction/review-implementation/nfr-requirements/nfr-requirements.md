# U3 NFR

기존 로컬 Node/React/Express/SQLite와 JSON/소속 검증을 재사용한다. 리뷰 요청/결과 내용은 64KiB, 목록은 기본 50/최대100과 키셋 추가 조회다. 전체 이력을 자동 삭제하지 않는다. 결과 중복 및 수동 완료는 저장 전제로 경합을 거절한다.

역할은 인증이 아닌 시연 UI다. 별도 네트워크 서비스/운영 확장/고가용성 요구는 없다. 실패는 초안을 보존하고 저장 결과를 확인한다. 의미 있는 검증은 원래 대상 고정, 리뷰 중 진행, 자체 승인 분리, 재열람/비교, 수동 완료와 기존 DB 보존이다. 확장 3개 N/A.
