# U3 사용 안내

루트에서 npm run dev를 실행하고 http://127.0.0.1:4310 을 연다. [전체 실행 안내](../../build-and-test/build-instructions.md)를 따른다.

헤더의 시연 역할에서 작성자/리뷰어를 선택한다. Inception 또는 Construction의 SR에서 문서를 열고 요청 내용을 입력해 리뷰를 요청한다. 리뷰는 계획 단계와 별도이며 대기 중에도 자체 승인 조건을 충족하면 계획을 진행할 수 있다.

리뷰어로 전환하고 요청 당시 버전 보기를 통해 원래 문서를 확인한다. 결과 내용을 입력해 리뷰 승인 또는 수정 요청을 기록한다. 대상 이후 편집이 있으면 이전 버전과 최신 버전 링크를 구분한다. 리뷰 결과는 AI-DLC 자체 승인이 아니다.

마지막 코드 구현 계획을 자체 승인해 구현 대기로 옮긴 뒤, 외부 구현을 끝낸 작성자는 구현 완료로 표시 버튼과 확인창으로 완료를 선언한다. 자동 빌드 검증이 아닌 수동 기록이다.

불확실 저장은 처리 결과 다시 확인으로 원래 리뷰/완료 결과를 조회한다. 새 시도 준비는 별도 확인 후 최신 상태를 읽고 입력을 유지하며, 자체적으로 새 요청을 보내지 않는다. 역할/화면 이동 시 초안이 있으면 확인창에서 취소하거나 명시적으로 버린다.

기존 DB는 앱 시작 시 schema v3로 마이그레이션된다. 이전 데이터와 기록을 보존한다. 기본 사용자 DB는 이번 검증에서 생성/초기화하지 않았다.
